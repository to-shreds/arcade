# Arcade 2.6.5 verification

## Changes

The shared web/Android main menu defaults to A-Z. Live search matches activity
titles and categories, trims spaces and ignores case. Existing type, player
and category filters intersect search and both order views. Clear removes the
query while retaining the other filters.

Recently used shows the last ten distinct available activities opened on this
device, newest first. Reopening moves an entry to the top. Only folder IDs are
kept in localStorage, separate from game saves; no account/server sync is used.
Malformed history is normalized, disabled/unknown activities are excluded,
and storage denial leaves current-session history usable. A reload starts in
A-Z while retaining saved history. Shell URL/invitation launches and legacy
native launches count, as do tiles. Home refreshes the list and preserves
keyboard focus on the replacement launch tile.

The Android 2.4.0 wrapper uses this same menu and validated offline archive.
No native source change or APK rebuild is required. Manually selected local
folders need the updated extracted web release.

## Verification

- `tools/test-catalog-browser.mjs` passed all 11 actual Chromium scenarios
  with zero JavaScript page errors. Checks include default alphabetical order,
  live case-insensitive title/category search, filter intersections, Clear,
  no matches, first-use Recent, real tile/shell/deep-link launches, newest-first
  order, unique last ten, repeat launches, Home focus, reload, same-browser tab
  updates, isolated browser storage, malformed/disabled/unknown history,
  rejected launches, storage denial and a controlled legacy native bridge.
- Both catalog and shell tests passed 1440x900, 390x844, 320x568 and 844x390.
  Actual screenshots were inspected. The added browse row initially overlapped
  cards because the persistent shell still allocated four rows; it now uses
  five. Regression assertions verify toolbar/grid separation and screen fit.
- The extended `tools/test-shell-browser.mjs` passed catalog filters, launch,
  browser Back/Forward, persistent shell identity, settings and Escape.
  Its real service-worker download reached Offline Ready, reloaded offline,
  opened Paint and returned Home. Another actual offline reload retained
  Recently used, live search, no-match and Clear behavior. A final offline
  reload restored the A-Z and empty-query defaults without losing history.
- Eight shell-core tests, all 45 enabled Home routes, native keyboard checks,
  and the Android wrapper source contract passed.
- All 187 Worker regression tests passed after binding shell CustomEvents to
  `window`, so browser and jsdom dispatch use events from the correct realm.
  The final catalog and offline shell browser checks were repeated and passed.
- The complete offline runtime passed manifest size/hash/import validation:
  360 files, 18,372,854 bytes, `2.6.5+20261011.2`.
- The downloadable ZIP is generated by `tools/package-web-release.py`, which
  verifies every packaged runtime byte/hash and tests ZIP integrity.

Generated browser screenshots and reports stay under ignored `test-results/`
and in CI artifacts. They are excluded from the downloadable release.

## Publication and limits

The canonical ProjectStatus entry records the source commit, Pages publication,
current full CI result and download identity. The checks above were run before
publication; no physical Android hardware testing is claimed. The native
fallback fixture tests the JavaScript bridge contract, while the real browser
flows use the persistent shell. Existing game content, saves, engines and
multiplayer authority are unchanged.

Refresh Arcade while online and update its offline copy to receive this menu.
